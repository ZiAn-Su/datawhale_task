## 第三章 模型演进
### N-gram
- N-gram的思想可以追溯到1913年，从1950-1990发展成熟，2010以后随着深度学习的兴起，N-gram模型不再是主流模型。
- 思想：基于马尔可夫假设，计算窗口内下一个词出现的概率。
``` 
** 训练 **
遍历文本库，统计所有N窗口的出现次数
训练好的模型本质上是一个巨大的“键值对”数据库。
    键： 历史上下文（前N-1个词），例如 ("I", )。
    值： 所有可能的下一个词及其概率，例如 {"am": 0.8, "have": 0.1, "think": 0.05, ...}。
** 应用 **
评估一个序列的概率，评价给定的句子或词序列的“流畅度”或“自然度”
生成新的文本
    与现在的模型相似，起始词 - 根据概率随机选择一个词 - 继续生成直到结束符
```
### 词嵌入、循环神经网络（RNNs，包括LSTM）为代表
RNN：核心思想为网络增加“记忆”能力，缺陷是受限于梯度消失/爆炸，难以捕捉长距离的依赖关系
LSTM：LSTM是RNN的一种特殊变体，以避免RNN的长期依赖问题，在长序列任务（如机器翻译、文档摘要、语音识别）上表现远优于RNN
### Transformer
- Transformer解决了RNN/LSTM的两个根本缺陷：     
1、顺序计算导致的低效训练       
2、长距离依赖信息捕捉能力不足

## 第四章 智能体经典范式
### ReAct
- 思想：通过提示词让模型在回答问题时，遵循思考-行动-观察的过程进行迭代，直到有足够的信息能够回答问题。
- 实现：设置提示词（提示词指定模型按照思考、行动固定格式回答，告诉模型工具列表、功能、用法）-大模型执行（得到思考和行动）-行动-记录模型的思考、行动、行动的结果考，将记录的信息追加到之前的提示词上-重复上述步骤
- 主要特点：高可解释性、动态规划与纠错能力、工具协同能力
- 局限性：对LLM自身能力的强依赖、串行执行的效率问题、对提示词的强依赖、可能陷入局部环节
- 实用工具：dotenv-解析.env环境变量；serpapi-搜索

### Plan-and-Solve
- 思想：规划-执行
- 实现：制定问题的具体可执行的子步骤-依次执行这些步骤
- 适用场景：适用于结构性强、逻辑路径确定、内部推理密集的任务
  
### Reflection 
- 思想：执行 - 反思 - 优化
- 实现：定义不同的对象分别执行执行、反思、优化，先执行出一个结果，然后循环进行反思-优化
- 能显著提升解决方案的质量，适用于对结果的准确性和可靠性有极高要求的场景
